# mpv keybinds

Most-used binds from `input.conf`. Anything not listed falls back to mpv defaults.

## Playback

| Key | Action |
|---|---|
| `Space` / `Enter` | Pause / resume |
| `q` | Quit |
| `<` / `>` | Speed −/+ 0.25 |
| `Backspace` | Reset speed to 1.0 |

## Seeking

| Key | Action |
|---|---|
| `←` / `→` | Seek −/+ 5 s |
| `Shift+←` / `Shift+→` | Seek −/+ 1 s |
| `Shift+↓` / `Shift+↑` | Precise seek −/+ 1 s |
| `,` / `.` | Seek −/+ 1 s |
| `[` / `]` | Seek −/+ 10 s |
| Scroll left / right | Seek −/+ 5 s |

## Volume

| Key | Action |
|---|---|
| `↑` / `↓` | Volume +/− 5 |
| Scroll up / down | Volume +/− 5 |
| `m` | Mute |

## Subtitles & audio

| Key | Action |
|---|---|
| `j` / `J` | Next / previous subtitle track |
| `k` / `K` | Next / previous audio track |
| `z` / `Z` | Subtitle delay −/+ 0.1 s |
| `Ctrl+z` / `Ctrl+Z` | Audio delay −/+ 0.1 s |
| `r` / `t` | Move subtitles up / down |

## Video & window

| Key | Action |
|---|---|
| `f` / double-click | Fullscreen |
| `T` | Always on top |
| `a` | Cycle aspect ratio |
| `s` | Screenshot with subtitles |
| `S` | Screenshot without subtitles |

Screenshots go to `~/Pictures/Screenshots`.

## OSD

| Key | Action |
|---|---|
| `p` | Cycle modernf controls visibility |
| `o` | Show progress bar |
